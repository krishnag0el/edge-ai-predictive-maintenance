# EXP-06: Filter Parameter Study

## Objective

Investigate how the cutoff frequency of a low-pass filter affects
the preservation and suppression of frequency components.

## Test Signal

The signal contains:

- 50 Hz component
- 120 Hz component
- 300 Hz unwanted component

## Cutoff Frequencies

The following cutoff frequencies will be compared:

- 80 Hz
- 150 Hz
- 200 Hz

## Goal

Determine how the cutoff frequency affects the 50 Hz, 120 Hz, and
300 Hz components.

## Status

Experiment in progress.
