# EXP-01: 50 Hz Sine Wave Generation

## Objective

Generate and visualize a 50 Hz sinusoidal signal in the time domain.

## Theory

A sinusoidal signal can be represented as:

x(t) = A sin(2πft)

where:

- A = amplitude
- f = frequency
- t = time

For this experiment:

- Amplitude = 1
- Frequency = 50 Hz

## Parameters

| Parameter | Value |
|---|---:|
| Sampling frequency | 1000 Hz |
| Duration | 1 second |
| Number of samples | 1000 |
| Signal frequency | 50 Hz |
| Amplitude | 1 |

## Method

1. Generate a time vector from 0 to 1 second.
2. Generate a 50 Hz sinusoidal signal.
3. Plot amplitude versus time.
4. Save the resulting plot as an image.

## Result

![50 Hz Sine Wave](sine_wave.png)

## Observation

The waveform is periodic and contains approximately 50 complete cycles during the 1-second observation interval.

## Conclusion

A 50 Hz sinusoidal signal was successfully generated and visualized in the time domain.
