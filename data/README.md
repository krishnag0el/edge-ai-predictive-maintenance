# Dataset Information

## Dataset

Case Western Reserve University (CWRU) Bearing Dataset.

## Source

Case Western Reserve University Bearing Data Center.

## Purpose

The dataset is used in this project to investigate vibration-based
bearing fault detection.

## Data Used

Only selected samples will be used for the experiments rather than
committing the complete dataset to this repository.

## Data Organization

The local dataset will contain vibration measurements representing
different bearing operating conditions.

## Reproducibility

The original dataset should be obtained from the official source
listed above.

Refer to EXP-07 for the preprocessing and analysis procedure.

## Important

The raw dataset is not stored directly in this GitHub repository.
